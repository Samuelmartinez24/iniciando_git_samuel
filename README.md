# 📘 Primera Clase - Jupyter en Codespaces

Proyecto configurado para trabajar con Jupyter Notebook en GitHub Codespaces.

## 🚀 Cómo usarlo

1. Crear Codespace desde GitHub.
2. Esperar que cargue el entorno.
3. Abrir la carpeta `notebooks/`.
4. Ejecutar `primera_clase.ipynb`.

## 📦 Librerías

- pandas
- numpy
- matplotlib
- seaborn
